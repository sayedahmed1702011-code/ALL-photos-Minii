# All Photos Mini

عارض صور محلي خفيف لنظام Windows، مبني باستخدام Python وTkinter ومكتبة Pillow. لا يستخدم الإنترنت أو قاعدة بيانات.

## الميزات

- يفحص المجلدات ومجلداتها الفرعية بحثًا عن JPG/JPEG وPNG وWEBP وBMP وGIF وTIFF وICO.
- يتيح إضافة مجلدات محددة أو بدء فحص جميع أحرف الأقراص المتاحة.
- يعرض النتائج في شبكة مصغرات افتراضية؛ تُنشأ مصغرات العناصر الظاهرة تدريجيًا في عامل خلفي، مع الاحتفاظ بذاكرة مؤقتة محدودة.
- يتيح البحث باسم الملف، وعرض معاينة محدودة الحجم والاسم والمسار والحجم.
- لا يحذف شيئًا تلقائيًا؛ الحذف يتطلب تأكيدًا صريحًا.
- يتعامل مع المجلدات التي لا تسمح صلاحيات Windows بقراءتها ويتجاوزها.

## التشغيل من المصدر على Windows

1. ثبّت Python 3.10 أو أحدث من [python.org](https://www.python.org/downloads/windows/) مع تفعيل خيار **Add Python to PATH**.
2. فك ضغط المشروع وافتح موجه الأوامر داخل مجلد `all-photos-mini`.
3. شغّل `run.bat`؛ سيبحث تلقائيًا عن `py` أو `python`. إذا لم يجد أيًا منهما، ثبّت Python كما في الخطوة الأولى ثم افتح ملف التشغيل مجددًا. ويمكنك أيضًا تنفيذ الأوامر يدويًا:

   ```bat
   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py app.py
   ```

## إنشاء ملف EXE

انقر نقرًا مزدوجًا على `build.bat`. بعد اكتمال البناء سيكون الملف هنا:

```text
dist\AllPhotosMini.exe
```

وللبناء اليدوي داخل البيئة الافتراضية:

```bat
py -m pip install -r requirements.txt
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --clean --onefile --windowed --name AllPhotosMini --collect-all PIL app.py
```

يشمل EXE المفسر والمكتبات اللازمة، لذلك سيكون أكبر من ملف Python نفسه، لكنه لا يحتاج Python مثبتًا على كمبيوتر الاستخدام. من الطبيعي أن يستغرق أول تشغيل للنسخة المجمعة وقتًا قصيرًا لاستخراج مكوناتها المؤقتة.

## إنشاء EXE دون تثبيت Python على جهازك (GitHub Actions)

يتضمن المشروع إعدادًا في `.github/workflows/build-windows.yml` يبني EXE على جهاز Windows مستضاف لدى GitHub. ستحتاج إلى حساب GitHub، لكن لا تحتاج إلى تثبيت Python على جهازك:

1. أنشئ مستودعًا جديدًا على GitHub، ويفضّل جعله **Private**.
2. ارفع ملفات المشروع إلى المستودع، مع تضمين مجلد `.github/workflows` وملف `build-windows.yml`.
3. افتح تبويب **Actions** في المستودع، واختر **Build All Photos Mini for Windows** ثم **Run workflow**. ويمكن تشغيل البناء تلقائيًا عند رفع تغييرات إلى `main` أو `master`.
4. بعد اكتمال البناء بنجاح، افتح نتيجة التشغيل، ثم نزّل الأثر **AllPhotosMini-Windows** من قسم **Artifacts**. فك ضغطه لتحصل على `AllPhotosMini.exe`.

لا تضع أسرارًا أو مفاتيح API في المستودع؛ عملية البناء لا تحتاجها. يحتفظ GitHub بملف البناء لمدة 30 يومًا وفق إعداد سير العمل.

## الاستخدام

- **اختيار مجلد**: أضف مجلدًا إلى قائمة الفحص. يمكنك إضافة أكثر من مجلد.
- **فحص المجلدات المحددة**: ابدأ الفحص للمجلدات الظاهرة في القائمة.
- **فحص جميع الأقراص**: يفحص أحرف الأقراص المتاحة في Windows؛ قد يستغرق ذلك وقتًا حسب حجم الأقراص والصلاحيات.
- **تحديث**: يعيد الفحص باستخدام قائمة المجلدات الحالية.
- انقر صورة لعرض معاينتها وتفاصيلها. استخدم مربع البحث لتصفية النتائج بالاسم.
- الحذف نهائي ويعرض رسالة تأكيد قبل تنفيذه.

## ملاحظات

- الفحص لا يتصل بالإنترنت ولا يعدل الصور. الصور المتحركة تعرض إطارها الأول.
- يتم تمرير ملفات الصور إلى Pillow لإنشاء نسخ مصغرة ومعاينات محدودة الأبعاد؛ لا يحتفظ التطبيق بنسخ الصور الأصلية في ذاكرة الواجهة.
- يُنصح ببناء EXE على Windows نفسه باستخدام `build.bat`؛ PyInstaller لا ينشئ عادةً ملف Windows EXE عند تشغيله على Linux أو macOS.
